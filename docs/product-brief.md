# 《临安梦华录》产品需求说明

> 产品复盘版。依据 2025 年项目脚本、分工和迭代材料，按 PRD 结构归纳需求、范围与交付约束。本文的优先级、编号及验收表在作品集整理阶段统一整理。

## 产品目标

面向对杭州与传统文化感兴趣的高校师生和年轻观众，以短视频呈现南宋临安的市井、点茶及学府意象。通过主角的穿越经历和任务推进，帮助观众理解场景间的联系，同时探索小团队使用 AIGC 完成多模态内容交付的方法。

## 用户与需求判断

| 对象 | 场景与需求假设 | 对应设计 |
| --- | --- | --- |
| 高校师生、年轻观众 | 对杭州历史和古画有兴趣，但需要容易进入的故事切口 | 现代学生视角、穿越开场、短视频表达 |
| 对宋韵文化感兴趣的观众 | 希望看到具有场景感的生活与技艺 | 市井、点茶、太学等具体内容 |
| 小型内容制作团队 | 多人分工、工具不同，片段容易在风格与逻辑上脱节 | 场景拆分、风格沟通、素材提交节点与人工检查 |

需求判断来自内容研究、同类作品分析和课堂展示反馈。现有材料不足以建立访谈样本、问卷统计或用户行为数据结论，因此将以上用户需求保留为项目假设。

## 内容参照与定位

原始方案参考了《梦华录》等宋韵题材作品、传统绘画及文博场景，也对线下文化体验进行了比较。本项目从中提炼的机会是：在较短的视频中，用任务线连接可视化的文化场景，使观众不必先理解大量历史背景就能进入故事。

作品采用带现代元素的穿越虚构，历史文化素材用于叙事创作。不能将生成画面直接解释为经过严谨考据的历史复原。

## 体验流程

1. **进入：**现代学生遭遇穿越事件，建立人物与情境。
2. **推进：**通过任务提示进入临安市井、点茶等场景。
3. **转折：**由生活体验过渡到太学与求学主题。
4. **结束：**回归现实，与现代学习处境形成呼应。

任务界面、工具提示和奖励承担视频叙事功能；当前交付形态为线性短片。

## MVP 范围与优先级

以下按已交付内容和原始方案归纳优先级，用于解释范围取舍。

| 优先级 | 需求 | 交付方式 |
| --- | --- | --- |
| P0 | 穿越开场、场景推进、现实回归形成观看链路 | 脚本与成片剪辑 |
| P0 | 市井、点茶、太学等内容可辨识 | 生成画面、字幕及声音共同表达 |
| P0 | 任务提示帮助观众理解当前场景 | 在成片中呈现任务或工具提示 |
| P0 | 各分工片段能进入统一时间线 | 片段提交、筛选、剪辑与转场 |
| P1 | 海报传达题材，标题可读 | 多版海报及文字调整 |
| P1 | 积累可复用的提示词表达 | Prompt 语料库与迭代记录 |
| 后续探索 | 观众选择剧情分支、文博导览合作、规模化素材生产 | 需要另行验证需求与技术路径 |

## 验收框架

从产品决策角度，需求可分为两类：**故事能否成立**决定场景和叙事优先级，**素材能否稳定制作**决定生成工具与实施方式。前者通过脚本和 Demo 讨论，后者通过实际生成结果判断，两者共同约束最终方案。

原始制作过程已有人工检查、退回修改和阶段展示。下表将这些关注点整理为可复用的检查项，**不是当时已执行的量化评分结果**。

| 维度 | 检查问题 | 未满足时的处理思路 |
| --- | --- | --- |
| 叙事连贯 | 观众能否理解主角目标、当前任务及场景变化？ | 调整脚本、提示字幕或转场顺序 |
| 指令遵循 | 主体、动作、环境是否符合镜头意图？ | 明确描述、调整参考图，必要时拆分动作 |
| 风格一致 | 相邻镜头的人物、画风和时代表达是否冲突？ | 对齐参考画面与风格词，替换不合适片段 |
| 动态稳定 | 是否出现明显变形、抖动或无意义运镜？ | 降低动作复杂度、重新生成或人工筛选 |
| 文字与声音 | 标题、字幕是否可读，声音是否与画面衔接？ | 人工修正与剪辑检查 |
| 文化表达 | 是否混入与预期场景冲突的时代、人物或器物？ | 核查素材；明确虚构设定与文化参照的边界 |

## 资源与交付约束

- 项目处于 2025 年春季至初夏的工具环境，采用多工具图像／视频生成、AI 生成配乐与人工剪辑。技术节点和团队使用边界见[技术背景说明](technology-context.md)。
- 四人团队分工生产，成员具有不同专业背景，工具熟练程度不一。
- 生成结果有随机性，复杂动作和跨镜头一致性需要人工筛选与修改。
- 分工文档要求先提交视频片段，再完成整片剪辑，体现了上下游交付依赖。
- 脚本 1.0 曾设想 5—8 分钟，最终留存成片约 2 分 04 秒。作品集以最终视频为交付口径，早期脚本用于说明探索过程。

## 后续验证计划

以下为复盘后的建议，尚无对应实验数据：

- **理解度：**组织少量目标观众观看后复述主角目标与场景关系，记录误解点。
- **内容记忆：**询问观众记住的文化内容，检验任务提示是否帮助理解。
- **生成可用率：**以“进入剪辑的候选片段数／生成候选片段总数”为口径，分工具、分场景记录。
- **单位交付成本：**同时记录生成耗时、人工筛选、修改与剪辑时间，避免只比较生成等待时间。
