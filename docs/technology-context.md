# 项目技术背景与时间核查

本项目开展于 2025 年 3—6 月，主要试验与迭代记录集中在 3—5 月。这里区分行业工具的公开时间与团队实际采用的制作方式，便于读者理解原始作品。

## Seedance 的时间参照

- **2025-06-11：**字节跳动发布 Seedance 1.0 官方介绍与技术报告文章，介绍其多镜头生成等能力。这是可核对的官方公开节点，不据此推断所有平台、账号的首次开放时间。[官方文章](https://seed.bytedance.com/zh/blog/tech-report-of-seedance-1-0-is-now-publicly-available)
- **2026-02-12：**Seedance 2.0 正式发布，官方介绍了多模态参考、音视频联合生成及编辑能力。[官方公告](https://seed.bytedance.com/zh/blog/official-launch-of-seedance-2-0)

因此，可以说本项目主要探索早于上述 Seedance 1.0 官方节点，更早于 Seedance 2.0。不能笼统地把整个 2025 年 6 月描述为“Seedance 尚未出现”。即梦是应用平台名，Seedance 是模型系列名；使用过即梦，也不足以倒推出当时使用的具体底层模型版本。

## Claude Code、Codex 与团队的工作方式

今天常见的这些编程 Agent 在项目期间处于早期推出阶段，具体时间需要区分：

| 工具 | 官方公开节点 | 与项目时间的关系 |
| --- | --- | --- |
| Claude Code | 2025-02-24，以有限研究预览形式推出 | 早于项目启动，但当时仍是早期预览形态 |
| Codex CLI | 2025 年 4 月推出 | 在项目进行期间出现 |
| 云端 Codex | 2025-05-16，推出研究预览 | 在项目后期出现 |

来源：[Anthropic 的 Claude Code 发布文章](https://www.anthropic.com/news/claude-3-7-sonnet)；[OpenAI 的 Codex 发布文章](https://openai.com/index/introducing-codex/)同时说明云端发布日期及 CLI 于前一个月推出。

因此，不宜写成“Codex、Claude Code 当时都没有出现”。更准确的表述是：**这些编程 Agent 当时处于早期推出或研究预览阶段，而本团队实际采用的是人主导、AI 辅助的制作方式。** 不用今天的产品形态倒推团队在 2025 年已经具备同样的工具条件，也不据此断言当时的 Agent 无法完成任何复杂任务。

本项目中，选题策划、脚本与任务设计、Prompt 调整、生成结果筛选、跨工具素材交接，以及最终剪辑均主要由成员组织和推进。AI 用于创意辅助、图像／视频素材和配乐生成，人的判断与协作承担了完整交付的组织工作。

### 更早的 Agent 背景

Replit 在 2024 年 9 月的官方文章中已介绍能够创建和部署应用的 Replit Agent，并说明其向 Core 订阅用户提供早期访问。[Replit 官方介绍](https://replit.com/blog/introducing-replit-agent)

这说明不能写“当时市面上没有 Agent”。但编程 Agent 的存在，也不意味着团队当时已经采用自动完成视频策划、生成、检查和剪辑的系统。本项目实际采用人工组织的多工具流程，生成和后期之间由成员交接。

## AI 剪辑当时是否存在

已有 AI 辅助剪辑功能。Adobe 介绍其于 2023 年推出 Text-Based Editing；2025 年 4 月 2 日又发布了 Premiere Pro 的 Generative Extend，用于延长视频和音频片段。[Adobe 功能回顾](https://blog.adobe.com/en/publish/2025/04/02/introducing-new-ai-powered-features-workflow-enhancements-premiere-pro-after-effects) · [2025 年发布公告](https://news.adobe.com/news/2025/04/new-ai-innovation-in-industry)

“已有辅助剪辑功能”与“全自动完成一部叙事短片”是不同能力层次。本项目以 AI 生成画面与配乐、人工筛选及剪辑完成交付，不将团队未使用某项功能表述为市场上不存在该功能。

## 工具名称与实际职责

团队使用即梦、LiblibAI、可灵、Midjourney 等 AIGC 工具，具体承担图像、海报和动态片段等不同任务。Midjourney 在本项目中的明确记录是图像与海报探索，其 V1 视频模型于 2025 年 6 月 18 日发布，因此不将本项目的 Midjourney 实践笼统写成视频生成。[Midjourney 官方公告](https://updates.midjourney.com/introducing-our-v1-video-model/)

配乐由 AI 生成，最终剪辑由团队成员完成。音乐工具名称暂不作未经确认的归属。

## 如何理解作品完成度

原始成片保留了当时的效果，也保留了风格切换、部分动作和转场不够自然等局限。以四人跨专业课程项目的交付范围看，作品完成了叙事设计、图像与视频生成、AI 配乐、人工剪辑和最终展示，形成了较完整的视听交付。

这里的“完整”指项目环节和成片结构，不表示行业排名或量化质量优势。作品的产品价值体现在：识别能力边界、选择适配工具、调整内容方案，并通过人工判断与团队协作推进交付。
