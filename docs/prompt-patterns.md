# Prompt 结构与使用示例

## 项目原始语料结构

项目留存的《Prompt 语料库》将提示词拆成以下维度：

> 风格＋拍摄方式＋时代＋人物形象＋人物动作＋环境＋色彩／光线／情感基调

语料包含画风、景别、视角、光线与情绪等词汇，便于把较模糊的创意转化成可调整的描述。

| 维度 | 在项目中的作用 |
| --- | --- |
| 风格 | 对齐画面的表现方向，减少多人产出的差异 |
| 拍摄方式 | 明确全景、近景、特写，以及视角与运镜意图 |
| 时代与环境 | 指定场景语境，降低无关现代或其他时代元素的混入 |
| 人物与动作 | 明确主体形象、服饰和当前行为 |
| 光线与情感 | 辅助表达场景氛围与故事节奏 |

## 原始海报 Prompt

以下摘自 4.28 汇报中署名刘思嫒的海报实践记录：

> 我想做一张插画风格的海报，画风华丽，海报内容是一个浙大学生意外穿越回南宋临安城，最终完成一系列任务回到现实世界并且找到坚持自己相关专业的意义。这张海报用于宣传我们的 aigc 短视频“临安梦华录”，不要出现其余文字。

记录同时说明，在这之后继续修正文字。它展示了题材、角色、任务与标题约束如何进入生成指令。

## 复盘后的镜头描述模板

下面是根据原始框架整理的可复用示例，**不是当时已验证成功的原始 Prompt**。

```text
镜头用途：表现主角进入临安市井，连接穿越开场与第一个任务。
时代与场景：以南宋临安市井为叙事背景的街道。
主体：沿用角色参考图中的主角和服装。
动作：主角缓慢向前走，观察街道两侧。
画面：中景，单一稳定镜头。
风格：沿用项目选定的视觉参考。
光线：自然日光。
约束：保持人物外观与服饰连续，不添加现代招牌或不可读文字。
```

**使用方式：**先检查静态图中的主体和场景，再补充动态描述；若结果不符，记录偏差并修改对应字段。不同工具对参考图、负向提示和运镜的支持不同，需按实际功能调整输入。

## 可复用的经验

- 将“好看”“有历史感”等形容词转为具体的人物、画面和光线条件。
- 发现错误时明确指出错误类型，避免只追加“更高级”“更准确”等模糊修饰。
- 把图像质量、动作完成度和剪辑可用性分别检查。
- 复杂动作若多次不稳定，应同时考虑调整镜头方案。
